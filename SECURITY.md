# Reporting a security issue

Use [GitHub's private vulnerability report](https://github.com/gatsbys/macos-toolbox/security/advisories/new). Include the Toolbox and macOS versions, what happened, and steps to reproduce it. Use invented clipboard entries and remove personal data from screenshots and logs.

For ordinary bugs and ideas, use [GitHub Issues](https://github.com/gatsbys/macos-toolbox/issues).
